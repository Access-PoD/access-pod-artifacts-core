# Contributors — APOD-ID3-RULE-001

## Maintainer / Specification Authority: Structural enforcement semantics only.

## Contribution scope (allowed)
- New validator types (structural only)
- Expanded required/optional field coverage (structural only)
- Improved diagnostics and severity classification (non-authoritative)
- Packaging discipline improvements (manifest/checksum/release notes)

## Out of scope (not accepted)
- Compliance scoring, adequacy grading, maturity models
- Legal/regulatory interpretations
- Any mechanism that infers or fabricates missing semantic content

## How to propose changes
1. Open a PR with:
   - updated rule JSON (and version bump),
   - CHANGELOG entry,
   - DIFF_NOTES describing compatibility impact,
   - evidence of test/validation.
2. Ensure non-fabrication boundary is preserved.
