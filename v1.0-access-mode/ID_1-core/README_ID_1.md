# Access-Mode ID_1 — Core (Learning)

**Status:** Informative, Non-Normative
**Audience:** General practitioners, researchers, designers, policy-curious professionals  
**Purpose:** Establish disciplined AI governance reasoning before runtime or regulatory specialization.

## What this mode is
ID_1 defines the foundational (learning) reasoning posture within the Access-Mode method.
It is commonly introduced through workshop materials, but the mode itself is independent of delivery format.

This mode is designed to be:
- architecture-agnostic
- system-neutral
- suitable as a first exposure to Access PoD thinking

## Module set
1. Module 01 — Governance AI Identity  
2. Module 02 — Intent, Scope & Boundaries  
3. Module 03 — Governance RAG & References  
4. Module 04 — Writing Governance Artifacts  
5. Module 05 — Access PoD Lens  
6. Module 06 — Forward Practice & Reflection  

All modules in this mode are **canonical copies** of the base workshop materials.

## How to use
- Use this mode for:
  - introductory workshops
  - mixed-discipline cohorts
  - early-stage governance capability building
- Outputs are conceptual, written, and reflective — not runtime-enforced.

## Editing and use rules

- This release is **learning-only (ID_1)**. All outputs are non-operational and non-inspectable.
- Use the modules in this folder as a **learning workspace**. You are expected to fill the priming modules with your own inputs.
- The worked examples in `/exemplar_modules/` are provided for **instructional reference only** and must not be copied verbatim.
- Do not mix priming and exemplar modules within the same project.
- For full context on release scope, posture, and correct usage, refer to:
  - `release_notes_ID_1.md` (canonical for this release)
  - *Access-Mode ID_1 — Core (Learning)* PDF (reading and orientation guide)
