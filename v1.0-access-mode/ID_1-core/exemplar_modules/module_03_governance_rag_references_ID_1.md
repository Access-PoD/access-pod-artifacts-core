# Module 3 — Governance Reference Discipline
## Bounded Retrieval for Standards-Aligned Reasoning

> This module copy contains a worked example for learning only.  
> It is non-operational and non-inspectable under Access-Mode ID_1.

HASH KEY progression (1–10) is defined in the README_ID_1 and used consistently across modules.

Access-Mode context:
This module is rendered under **ID_1 — Core / Learning** posture.
References are treated as conceptual anchors only.
No authority resolution or inspection weighting is permitted.

---

## Purpose

This module establishes **reference discipline** for governance work supported by AI.

In governance contexts, errors rarely come from incorrect language generation.
They arise when **unbounded references**, **informal interpretations**, or
**implicit assumptions** are allowed to influence reasoning.

This module defines how reference materials function as **governance-grade
retrieval anchors**, ensuring that AI assistance operates only within
explicitly permitted sources and interpretations.

---

## HASH KEY 1 — Purpose of Retrieval

**Why are references being retrieved at all?**

Answer clearly before selecting any source.

- Are references used to interpret standards?
- To explain obligations?
- To compare positions?
- To provide contextual grounding only?

> References are retrieved in this work to provide conceptual grounding and shared vocabulary for governance discussion, not to determine obligations, adequacy, or compliance.

---

## HASH KEY 2 — Reference Categories (Allowed Sources)

**Identify what types of references are permitted.**

Common categories include:
- formal standards (e.g. ISO, IEC),
- statutory or regulatory texts,
- official guidance or consultation drafts,
- internal policy frameworks,
- prior governance decisions.

List explicitly:
- **Allowed reference categories**
- **Disallowed reference categories** (blogs, commentary, unofficial summaries)

> Allowed: Formal standards as labeled artifacts; statutory or regulatory texts as descriptive inputs; official guidance or consultation drafts for context; internal policy frameworks for orientation.
> Disallowed: Blogs, opinion pieces, secondary summaries, marketing material, or uncited “best practice” claims.

---

## HASH KEY 3 — Authority Weighting

**Not all references carry equal authority.**

For each allowed category:
- which sources are authoritative?
- which are contextual only?
- which must never override formal instruments?

> In the event of conflict, priority is given to formally issued standards or statutory texts over guidance, drafts, or internal materials. Contextual sources must never override formal instruments.

---

## HASH KEY 4 — Interpretation Boundaries

**Define how references may be interpreted.**

Consider:
- literal reading only?
- contextual explanation permitted?
- synthesis allowed but not reinterpretation?

Explicitly state:
- what AI may summarise,
- what AI may not infer.

> AI may summarise or explain provided reference text at a descriptive level. AI must not infer obligations, extend meaning beyond the text, or reinterpret standards language.

---

## HASH KEY 5 — Reference Currency & Versioning

**Clarify time sensitivity of references.**

- Are only current versions allowed?
- Are superseded drafts excluded?
- How are amendments or consultations handled?

Complete:
> References are considered valid only if they are current as-of the stated context. Superseded versions are excluded, and drafts or consultations are treated as contextual only.

---

## HASH KEY 6 — AI Retrieval Boundary (Critical Control)

**Define the retrieval limits placed on AI.**

- Can AI retrieve only provided documents?
- May it generalise beyond supplied text?
- Is external retrieval disabled or constrained?

> AI retrieval is limited to the references explicitly provided in this workspace. AI must not perform external retrieval or generalise beyond supplied text without explicit human instruction.

---

## HASH KEY 7 — Exercise: Reference Map

This exercise makes reference authority and usage **explicit before drafting begins**.  
The goal is not completeness, but defensibility: every reference used must have a
clear role, authority level, and interpretation boundary.

**Exercise (20 minutes)**

Create a simple reference map using the table below.

| Reference | Category | Authority Level | Allowed Use |
|---|---|---|---|
| ISO/IEC standard (excerpt) | Formal standard | Primary | Literal citation and contextual explanation |
| Regulatory guidance note | Official guidance | Contextual | Orientation only |
| Internal policy framework | Internal framework | Contextual | Internal alignment reference |
| Consultation draft | Draft guidance | Contextual | Illustrative context |
| Prior governance decision | Internal record | Contextual | Historical reference |

**Instructions**

- Populate at least **five references** relevant to your current work.
- For each reference, explicitly state:
  - its category,
  - its authority level,
  - and how it may be used.
- If a reference cannot be clearly classified, **it should not be used**.

This exercise is complete when:
- authority differences are visible,
- contextual sources are not mistaken for governing ones, and
- AI cannot silently elevate informal material into authoritative reasoning.

## HASH KEY 8 — Case Prompt (Drift Test)

Case prompts are optional and intended for deeper stress-testing where time permits.

**Scenario**

AI introduces a phrase:
> “Best practice suggests…”

- Is “best practice” defined?
- Is a source cited?
- Does this phrase introduce an unstated authority?

Write how you would:
- identify the issue,
- correct the draft,
- prevent recurrence.

> The phrase “best practice suggests” introduces unstated authority. I would flag it, remove the phrase, and replace it with a cited source or reframe the sentence descriptively to avoid implied endorsement.

---

## HASH KEY 9 — Reflection Checkpoint

Reflect:

- Which references do you rely on most often?
- Where have informal sources influenced past work?
- What feels uncomfortable to exclude?

> I rely heavily on guidance documents because they are easier to read than standards, even when they carry less authority. Excluding them feels uncomfortable but improves clarity about what actually governs.
