## Read the release documentation first

Start with `README_ID_1.md` and `release_notes_ID_1.md`. The latter is the source's canonical release-structure and usage reference. The root `Access-Mode ID_1 — Core (Learning).pdf` is its reading and orientation companion. `docs/README_doc_orientation.md` assigns method interpretation to Version E, practical setup to `docs/Access_Mode_Project_Guide.pdf`, and artifact-state explanation to E.2.

The source's normal workflow is human learning:

1. Read Module 01 in both the priming and exemplar sets to understand their roles.
2. Complete all six priming modules in sequence with the learner's own inputs, bounded AI assistance, exercises and reflection.
3. Keep the priming and exemplar sets in separate projects. For each single-mode setup, the Project Guide pp.23–26 specifies the mode README, its control and one six-module set. The root README is `README_ID_1.md`; each set supplies its own `Learning_mode.md`.
4. Compare tone, assumptions, scope and authority language; retain human source checks and revisions. The release describes this comparison as a learning technique, not an efficacy test or validation result.

The release remains learning-only and non-operational. Its IDs are posture examples, not compulsory maturity stages. The imported files are preserved publication copies; conduct any later learning exercise in a separate working copy. No answers, ratings or participant records were completed during migration.

## Learning review and source roles

These are current reading clarifications for the preserved learning-only modules. Historical uses of *inspectable* or *auditable* describe making a responsibility table, draft paragraph or source map clear enough to review within a learning exercise. They do not make the result an ID3 inspection artifact or a governance determination.

Module 03 combines a learning-only prohibition on authority resolution with an authority-priority exercise. Read that exercise as recording the source roles and priority assumptions declared for the learning work, and flag unresolved conflicts. A learning source map does not determine legal or regulatory authority, resolve an external standards conflict or confer approval.

Treat the original phrase *canonical copies* as a lineage description in this reading route, not as evidence of byte identity or interchangeability. The standalone priming modules, worked exemplars and early embedded modules are distinct sets. Use priming modules for learning work in a separate working project and exemplars in a separate reference project.
