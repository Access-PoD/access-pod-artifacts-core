# Original Access-Mode publication: mode examples

Collection navigation note, 11 October 2026. These three subfolders preserve the early mode examples supplied in the original Access-Mode base release. This README is a new collection index; the original mode files remain unchanged.

These early examples include unfilled module scaffolds and historical status labels. Their presence records the original method templates; it is not evidence that a learning, operational or inspection exercise has been completed. The later standalone examples linked below remain separate releases.

Start with the [original base-release README](../README.md) and the [base folder guide](../ERRATA.md).

The later standalone folders sit directly under `v1.0-access-mode/`, alongside `modes/`. They have their own release histories and contents; they are not described as byte-identical copies of these early examples. No standalone files have been merged into the original mode folders.

The IDs illustrate different reasoning postures, not required stages or a maturity ranking. Historical wording remains part of the preserved publication.
