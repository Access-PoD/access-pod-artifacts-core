# Module 02 — normative_language_iso_phrasing (ID_3 Primer)

HASH KEY progression (1–10) is defined in the ID_3 control file and used consistently across modules.

Access-Mode context:
This module is rendered under **ID_3 — Inspection / Standards** posture.
It establishes language discipline for inspection-facing artifacts.
No compliance, adequacy, certification, or approval claims are permitted.
Outputs remain draft and inspection-oriented.

---

## Purpose

Define how normative language is identified, constrained, and inspected in AI-assisted governance artifacts.

Language must not create unintended obligation, authority, or endorsement.

Structural clarity does not create mandate or compliance standing.

---

## Outcomes

By completing this module, the operator can:

- distinguish descriptive language from prescriptive obligation
- identify authority drift introduced through phrasing
- constrain AI-generated normative language
- prepare inspection-defensible language structures
