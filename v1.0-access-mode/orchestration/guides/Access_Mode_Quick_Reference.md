Access-Mode Quick Reference

For Facilitators and Reviewers

1. What Access-Mode Controls

Access-Mode controls how the AI reasons, not what it decides.

It is applied at the project level, not per message.

2. The Three Access-Modes (at a glance)
ID_1 — Learning

Purpose: Explain and understand
Focus: Definitions, intent, scope
Avoid: Runtime behavior, inspection, compliance

Ask: “What does this mean?”

ID_2 — Mentor (Operational)

Purpose: Explore behavior under use
Focus: Stress, drift, failure, uncertainty
Avoid: Approval, adequacy, compliance

Ask: “What happens under pressure?”

ID_3 — Organizer (Inspection)

Purpose: Prepare content for review
Focus: Structure, clarity, assumptions
Avoid: Runtime simulation, decisions

Ask: “How will this be read?”

3. Core Discipline Rules (non-negotiable)

One project = one primary mode

Secondary modes may assist, never decide

Never switch primary modes mid-session

If posture must change → switch projects

Prompts refine behavior; project setup controls it

4. Single-Mode Projects (default)

Upload:

6 modules from one mode only

Do not upload:

modules from other modes

organizer_mode.md

Recommended titles:

My AI Governance — Learning

My AI Governance — Mentor

My AI Governance — Organizer

5. Mixed-Mode Projects (advanced)

Use only when necessary.

Upload exactly:

6 modules (primary mode)

6 modules (secondary mode)

1 organizer_mode.md

Rules:

One primary mode only

One secondary mode maximum

organizer_mode.md is mandatory

6. Approved Mixed-Mode Patterns

ID_1 → ID_2
Learning with operational perspective

ID_1 → ID_3
Learning with inspection clarity

ID_2 → ID_3
Operational reasoning, organized for review

All other combinations are not allowed.

7. Validation (always required)

After generating content:

Remove or alter 2–3 elements

Re-run the model

Check whether errors are detected or invented

Also ask:

“What assumptions are inferred?”

“What would a reviewer challenge?”

8. When to Stop

Stop or reset if:

the AI ignores mode limits,

certainty increases without evidence,

learning, operation, and inspection blur together.

Restart by:

restating the opening instruction, or

switching to a different project.

Key Reminder

Access-Mode is a discipline, not a feature.
Human judgment is always final.
