## Original publication and later examples

The original `modes/` payload remains intact. Its added README is a collection navigation note. The standalone ID folders are later release examples; they do not replace those early modes. ID1–ID3 describe distinct reasoning postures, not a mandatory progression or maturity scale.

Inside ID2, the original two-candidate artifacts remain at the component root. The four-candidate extension stays in `ID_2-Access/four-candidates/`. Its additional cases extend the comparison example; they do not create a new posture or demonstrate four-candidate ID3 inspection/freeze coverage. Any further implementation needs its own stated scope and assessment.

For an initial single-mode project, read the current collection note first, then use the selected mode's README, actual control file and all six numbered priming modules in a separate working project.

The six numbered Markdown modules are distinct from the control file and supporting PDFs. Keep worked exemplar modules in a separate reference project; preserve the supplied primers and examples, and record new answers and adaptations in working copies. Check the [base errata](ERRATA.md) before applying older quick-reference or mixed-mode setup text.

ID1 uses sources to support learning and reflection. ID2 uses scoped references and records to support exploratory reasoning. ID3 examines selected records and reference material within its declared inspection boundary. Identify the references and assumptions used for a project, and read source-priority wording with the current component notes. Describing a source as authoritative in an example does not by itself determine legal authority, compliance or a new project's conclusions.

Source examples contain prefilled answers, checked options and historical status labels. These describe the supplied example, not a new user's acknowledgement, decision or demonstrated runtime outcome. The control files state project rules; their presence alone does not prove that a system enforces them.

For current reading corrections, use the [ID1 errata](ID_1-core/ERRATA.md), [ID2 migration notes](ID_2-Access/MIGRATION_NOTES.md) and [ID3 migration notes](ID_3-operator/MIGRATION_NOTES.md).
